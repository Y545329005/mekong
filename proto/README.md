# Mekong 算力平台 · 交互原型说明

P2P GPU 算力市场的可点击规格原型。单文件、零构建：React 18 UMD + Babel standalone + Tailwind，全部经 CDN 加载，浏览器直接打开即可运行。

> 本文件是对客版说明。内部实现排期、评审记录与裁决过程不在此文档范围内。

## 运行

```bash
npm install
npm run dev
# 打开 http://localhost:8787/proto/index.html
```

也可直接用浏览器打开 `proto/index.html`，或使用任意静态服务器。**需要联网访问 `cdn.jsdelivr.net`**（React / Babel / Tailwind 均由 CDN 加载；断网时页面顶部会出现降级提示）。

## 页面

| 入口 | 说明 |
|---|---|
| `index.html` | 租户 + 宿主双主体。导航：控制台 / 行情 / 实例 / 账单 |
| `admin.html` | 平台管理端：大盘 / 市场管理 / 资金对账 / 用户与合规 / 审计 |
| `enterprise.html` | 企业客户入口：提交算力采购需求，进入线下对接流程 |

`index.html` 与 `admin.html` **同源共享 localStorage**，双开两个 tab 可演示「用户操作 → 后台实时看见 → 后台干预 → 用户端生效」。

## 账户模型

**单登录账号 + 双主体**：登录层统一，租户与宿主是同一账号的两种角色，账本与凭据按主体分立。首次切换到宿主视角需接受 hosting agreement（账号级只确认一次）。

## 市场供给三源

市场由三类供给拼接，报价卡以来源标签区分：

| source | 来源 | 卡片标签 | 特征 |
|---|---|---|---|
| `offer` | 平台实测采样 | **已验证** | 完整规格与可靠性指标 |
| `seed` | 平台首发池（自购/签约） | **首发池** | 平台实测规格，可靠性 100% |
| `host` | 第三方宿主上架 | **宿主上架** | 实名 + 押金约束；硬件参数以 Agent 上报为唯一事实源 |

**宿主上架流程为 Agent 化三步**：安装 Agent（一次性注册 token）→ Agent 联网注册并自动上报硬件清单（宿主不可手填）→ **平台实测通过后才解锁定价并上架**。实测值（DLPerf / 性价比 / TFLOPS / CUDA）显示在报价卡上；**可靠性保持「—」**，因为实测 ≠ 履约，可靠性数据需真实成交积累。

## 计费与资金

- **双 SKU**：按量租用（On-Demand）· 时段订单/预订。时段订单锁价预付，**订单之间按半开区间互斥**（同一机器的占用时段不可重叠）。
- **资金托管**：下单预留冻结，按消费释放；**余额耗尽自动停机**（停机同时释放托管）。
- **带宽计费**：按量租用运行期按流量计费，与宿主收益分流同步。
- **对账可追溯**：账单页每笔流水带「余额」快照（写入时值）与「流水号」，每行自身可自证。
- **申请制出金**：宿主收益页「提现」提交申请（金额 + 通道 + 实到预估一次确认）→ Admin 资金对账审批 → 放行才扣减可提现余额。同账号同时仅一笔在审。**出金不产生计费流水**。

## 信任与合规

- **最终用途声明**前置到注册协议，注册时逐项确认，**下单零打断**。
- 租客侧资金托管 + 余额不足自动停机；宿主侧实名（必）+ 可选押金方可上架。
- 受限型号在下单前执行受限方与地域筛查。

## 行情页

由当前在售报价**实时派生**：各型号价格分布（起租价 / 挂牌中位价 / 主流价格区间）、地域分布、12 周趋势、供给与需求侧汇总。

**数据口径（重要）**：
- 「成交样本」仅取自**当前会话**的订单，样本量极小，仅作示意，**不参与价格区间计算**；
- 历史趋势为**示意序列**，非真实成交统计，**不作为定价依据**；
- 指标口径为「在售」（含平台实测与首发池供给），非「在线」。

## 企业客户入口

当前定位是**采购需求受理漏斗**，不支持平台自助下单：提交需求（用途 / 型号 / 卡数 / 周期 / 预算 / 联系方式）→ 生成受理编号 → 进入线下对接流程。

**企业合同、统一交付责任、SLA 与统一账单尚在规划中，当前不构成承诺。**

## 演示账号

- 注册：任意邮箱（如 `test@demo.dev`）+ 密码 `password123` + 任意 6 位验证码
- 管理端内置演示账号
- 页面底部「评审工具」条可重置余额、模拟时钟加速、清除重来（正式产品无此栏）

## 多语言

界面支持中文 / English 切换，选择持久化。行业术语（SSH / Docker / DLPerf / PCIe / $/hr 等）两语言保持原文；产品界面文案按用户语言呈现。

## 已知边界

- 数据均为**演示 mock**，非生产数据；宿主收益为前端守恒演示，非引擎结算实现。
- 流水窗口有上限，长会话下「跨行求和 = 余额差」仅在窗口内成立，以余额主卡片为准。
- 带宽为**模拟流量**（无真实流量源），按运行期平滑累积。
- Agent 上架流程为同步模拟（进度条 ~3s），真实系统为异步状态机，不含跨会话中间态与失败重测分支。
- 存储费为**过渡态**口径：机器停止后按上浮单价持续计费，计费参数归平台侧（对客只读）。
- 键盘可达性：ESC 关闭弹窗与焦点陷阱已实现，但未经自动化按键测试。
